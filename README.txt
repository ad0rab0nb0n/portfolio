What's included
- index.php: responsive portfolio built with PHP, HTML, and CSS.
- assets/profile.png: portrait extracted from the CV you provided.
- assets/bonbon-cv.pdf: copy of the CV you provided for the View CV button.

Run locally
1. Open this entire bonbon-portfolio folder in VS Code.
2. Open VS Code Terminal in this folder.
3. Run: php -S 127.0.0.1:8000
4. Open: http://127.0.0.1:8000
5. Keep the terminal running while previewing the site. Press Control+C to stop the server.

Before publishing
- Add your GitHub profile URL to $githubUrl in index.php.
- Add your LinkedIn URL to $linkedinUrl if you want it shown.
- Upload FitXplosion to GitHub, then add its repository URL to the FitXplosion project's 'url' value in $projects. The card currently says the repository is coming soon.
- Add GitHub/live demo URLs and case-study screenshots to other projects when available.
- Add certificate verification URLs where you have them.
- Check all project descriptions and credential names before publishing.
- The attached CV contains your personal email and phone number. Keep the View CV button public only if you're comfortable sharing those details; consider making a public CV copy with only the contact details you want to share.
